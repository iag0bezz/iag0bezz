## Projetos em destaque

**[AntiGrabber](https://github.com/iag0bezz/Anti-Grabber)** — serviço Windows de segurança defensiva contra grabbers (roubo de sessão do Discord, Steam e outros apps). Detecção 100% por metadado/comportamento via WinDivert, sem MITM, sem telemetria. C# .NET + tray Electron.

**Rexie Auth** — sistema de licenças para FiveM com Discord Bot, API e painel web, monorepo Node.js com MariaDB.
